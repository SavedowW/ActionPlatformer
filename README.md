Just a small action platformer I'm working on in my spare time. Uses SDL3, entt, nlohmann-json, openGL, glm, built with cmake. Tiled is used for tilemap editing, the game only needs JSON map and images of tilesets

# Animation format
Used to use a custom animation format, now now each directory with json with the same name in animations directory is interpreted as an animation, file postfixes are retrieved from that json.
